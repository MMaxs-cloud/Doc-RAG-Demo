# Technical RAG 0.6

Статус на 24 ноября 2026 года. Windows-развёртывание и поисковый контур проверены. Критерии с недоступными внешними зависимостями остаются открыты.

## Реализовано

- FastAPI, SQLite WAL с миграцией, файловое хранилище, уникальные идентификаторы и SHA-256.
- Шесть адаптеров, каноническая модель, фиксированный чанкинг 512/80, карта исходных координат и диагностика кодировок.
- Отдельный worker и embedding-сервис, публикация по поколению, аренда задания с heartbeat, отмена, повтор и reconciliation.
- Qdrant с cosine Dense, полнотекстовым BM25 и RRF в одной коллекции. Фильтры формата, года, языка и выбранных документов.
- Два адаптера генерации, локальный подсчёт токенов, SSE, сохранение истории, повтор генерации на сохранённой выдаче и проверка источников.
- React с режимами чата и поиска, управлением корпусом, PDF.js и текстовыми viewer, настройками и диагностикой.
- Скрипты Windows, Compose с сетевой изоляцией парсера, offline backup/restore и демонстрационный набор из шести форматов с 40 вопросами.

## Состояние критериев приёмки

| Критерий | Результат |
| --- | --- |
| FastAPI, React, сохранение состояния, фоновые задания | Проверены сборка и запуск Windows-скриптом с отдельным worker. Загрузка, индексация и поиск прошли через живой HTTP и Vite. |
| PDF, DOCX, TXT, MD и HTML | Реальный прогон загрузки, индексации, поиска, скачивания, переиндексации и удаления. Для PDF также отдельно проверены структура, таблица и страницы через Docling. |

| Чанкинг 512/80, исходные диапазоны | Unit-тесты и реальные индексации исходным tokenizer. |

| Dense, BM25, Hybrid и смешанный запрос | Реальный Qdrant 1.20.2. Проверены пять форматов, общий запрос PDF + Markdown и нагрузка из 24 запросов с параллельностью 4. |
| SSE, история, координаты, скачивание, удаление и переключение LLM | API и интерфейс проверены автоматизированными тестами. Сценарии провайдера в этих тестах используют моки. |
| GigaChat API | **BLOCKED**. Учётные данные отсутствуют. OAuth, refresh, SSE и обработка лимитов покрыты тестами адаптера. |
| GigaChat Lightning | **NOT VERIFIED** до окончания проверки официального GGUF. Адаптер и подсчёт токенов реализованы. |
| Docling layout и OCR | Реально проверены локальные Heron, TableFormer FAST, физические страницы и таблица. Опциональный OCR **NOT VERIFIED**. |
| Docker Compose | **BLOCKED** для запуска. Docker Engine и WSL отсутствуют в проверенной системе. |
| Backup и restore | Проверены целостность SQLite и файлов, запуск восстановленного Qdrant и поиск по сохранённому корпусу. |
| Перестроение полного индекса | Реализовано через очередь и новую версию коллекции в период обслуживания. Атомарное переключение alias отсутствует. |

## Решения и ограничения

Выбран нативный BM25 Qdrant 1.20.2 с REST Query API. Карточка Giga Embeddings определяет mean pooling, L2-нормализацию, размер 1024 и формат instruction. Для нераспознанных PDF сохраняется диагноз, а производные материалы хранятся отдельно от оригиналов. Для Word используются разделы и абзацы.

Подготовка коммерческой поставки требует выбора лицензионной схемы PyMuPDF. Параметры эксплуатации, измерения и точные команды проверки приведены в [отчёте](docs/REPORT.md), [инструкции Windows](docs/INSTALLATION_WINDOWS.md) и [описании ограничений](docs/KNOWN_LIMITATIONS.md).

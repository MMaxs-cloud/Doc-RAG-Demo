# Отчёт Technical RAG 0.6

## Среда и версии

Windows, Python 3.12.3, Node.js 24.21.0, npm 11.19.0 и Git 2.45.2. NVIDIA GeForce RTX 5070 с 12 227 MiB VRAM, драйвер 616.92. Для GPU-проверки использован Torch 2.13.0+cu130, для CPU-проверки Torch 2.15.0. Qdrant 1.20.2, FastAPI 0.165.0, PyMuPDF 1.26.7, python-docx 1.2.0, Docling 2.152.0, React 19.2.5, TypeScript 5.9.3, Vite 7.3.8 и PDF.js 5.4.624. Полные версии находятся в lock-файлах.

Модель embeddings `ai-sage/Giga-Embeddings-instruct-480M-0826` проверена на ревизии `1763d603adac8057bd6482a708001b0ed2e0a903`. Выбрана официальная `GigaChat3.1-10B-A1.8B-q4_K_M.gguf` и llama.cpp b12669. Для облака имя модели задаётся оператором через конфигурацию.

## Проведённые проверки

- Реальный Qdrant подтвердил BM25 payload index и три режима поиска. Для шести форматов проверены загрузка, извлечение, индексация, поиск, скачивание, переиндексация и удаление. Смешанный поиск нашёл PDF и Markdown в общей коллекции. Реальную генерацию и завершение жизненного цикла повторили после перезапуска на сохранённом индексе.
- CUDA embedding inference вернул 1024 значения и L2-норму около 1. Cosine для контрольного факта составил 0,744, для несвязанного документа −0,023.
- Backend pytest: 26 пройдено, 2 пропущено в обычном прогоне. Live GPU и CPU: по одному успешному тесту с настоящими inference и Qdrant. Сборка frontend и пять тестов Vitest прошли. Два теста Playwright прошли. Они проверили загрузку, прогресс, поиск, SSE, историю, просмотр, скачивание, смену провайдера и удаление через контролируемый API, а также отрисовку страниц настоящего PDF через PDF.js.
- LibreOffice 26.8.3.1 прошёл проверку конвертации настоящего DOC, повторного структурного разбора и предпросмотра DOC и DOCX. Исправлена очистка профилей с путями длиннее лимита Win32. Проверен реальный повторный запуск конвертации с удалением временных файлов. Прогон семи тестов парсеров с LibreOffice и Docling завершился успешно.
- Официальный GGUF проверен по SHA-256. Lightning через llama.cpp b12669 на CPU ответила на отдельный вопрос по каждому из шести форматов. Проверены потоковый ответ по PDF и Markdown, ссылки на оба источника и сообщение об отсутствии серийного номера в корпусе.
- Основной PDF-парсер Docling с локальными Heron и TableFormer FAST извлёк заголовки, блоки на обеих страницах и таблицу. Холодный прогон на CPU занял 34,46 с.
- На Windows проверен запуск одной командой, автоматический выбор порта llama.cpp при занятом 8080, загрузка и индексация отдельным worker через Vite proxy. После остановки сервисов, резервного копирования и восстановления SQLite и Qdrant проверены поиск, скачивание и ответ Lightning с цитатой через Vite.
- Учётные данные GigaChat API не были предоставлены. Тесты адаптера не отправляли документы внешнему сервису.

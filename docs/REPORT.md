# Отчёт Technical RAG 0.6

## Среда и версии

Windows, Python 3.12.3, Node.js 24.21.0, npm 11.19.0 и Git 2.45.2. NVIDIA GeForce RTX 5070 с 12 227 MiB VRAM, драйвер 616.92. Для GPU-проверки использован Torch 2.13.0+cu130, для CPU-проверки Torch 2.15.0. Qdrant 1.20.2, FastAPI 0.165.0, PyMuPDF 1.26.7, python-docx 1.2.0, Docling 2.152.0, React 19.2.5, TypeScript 5.9.3, Vite 7.3.8 и PDF.js 5.4.624. Полные версии находятся в lock-файлах.

Модель embeddings `ai-sage/Giga-Embeddings-instruct-480M-0826` проверена на ревизии `1763d603adac8057bd6482a708001b0ed2e0a903`. Выбрана официальная `GigaChat3.1-10B-A1.8B-q4_K_M.gguf` и llama.cpp b12669. Для облака имя модели задаётся оператором через конфигурацию.

## Проведённые проверки

- Реальный Qdrant подтвердил создание BM25 payload index и выполнение трёх режимов поиска. Загрузка, извлечение, индексация, поиск, скачивание, переиндексация и удаление прошли для пяти форматов. Смешанный поиск принёс оба целевых формата из общей коллекции.
- CUDA embedding inference вернул 1024 значения и L2-норму около 1. Cosine для контрольного факта составил 0,744, для несвязанного документа −0,023.
- Backend pytest: 23 пройдено, 2 пропущено в обычном прогоне. Live GPU и CPU: по одному успешному тесту с настоящими inference и Qdrant. Сборка frontend и пять тестов Vitest прошли. Два теста Playwright прошли. Они проверили загрузку, прогресс, поиск, SSE, историю, просмотр, скачивание, смену провайдера и удаление через контролируемый API, а также отрисовку страниц настоящего PDF через PDF.js.
- Основной PDF-парсер Docling с локальными Heron и TableFormer FAST извлёк заголовки, блоки на обеих страницах и таблицу. Холодный прогон на CPU занял 34,46 с.
- На Windows проверен запуск одной командой, загрузка и индексация отдельным worker через Vite proxy, а также поиск и скачивание после остановки сервисов, резервного копирования и восстановления нового SQLite и Qdrant.
- Учётные данные GigaChat API не были предоставлены. Тесты адаптера не отправляли документы внешнему сервису.

## Метрики

Пробный корпус мал. Измерения включают API, вызовы inference и SQLite и описывают только этот прогон.

| Операция | Измерение |
| --- | --- |
| Первый документ TXT, с холодным запуском tokenizer | 82,56 с |
| MD, HTML, DOCX, PDF, по одному чанку | 6,59–11,02 с на документ |
| Фоновая публикация первого TXT при реальном Windows-запуске | 60,64 с |
| Dense, пять запросов с фильтрами | 135–232 мс |
| BM25, пять запросов с фильтрами | 14–105 мс |
| Hybrid, пять запросов с фильтрами | 129–238 мс |
| Embeddings, два документа и один запрос на CUDA | 3,34 с |
| Embedding-сервис на CPU, RSS после нагрузки | 2 362 MiB |
| Hybrid на CPU, 24 запроса, параллельность 4 | p50 1 226 мс, p95 1 507 мс, 3,29 запроса/с, 0 ошибок |

Индексирование маленьких файлов включает запуск процесса парсинга и первичную инициализацию Python. Для локальной генерации фактические метрики ещё не подтверждены. Снимок всей GPU после запуска embedding-процесса составил 2 113 MiB, исходный снимок 1 126 MiB. Это не измерение изолированного пика модели.

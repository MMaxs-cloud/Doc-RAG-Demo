# Безопасность

- Загрузка ограничена на границе HTTP и на уровне отдельного файла. Проверяются расширение, MIME, сигнатуры, структура DOCX, пределы распаковки и имена ZIP entries. Файловые пути формируются из UUID.
- Контейнер parser работает без сети и с ограничениями CPU, RSS, размера выходных файлов, числа процессов и времени выполнения. LibreOffice использует отдельный временный каталог, уникальный профиль и явные настройки отключения макросов. После обработки временные файлы удаляются.
- Оригиналы выдаются в режиме attachment. HTML preview создаётся из экранированных блоков и содержит запрет активного содержимого через Content Security Policy. PDF.js рисует страницы без выполнения JavaScript. Markdown и текст отображаются через безопасное экранирование React.
- Production требует HTTP Basic Auth. Используйте TLS proxy для удалённых пользователей. Сторонние Origin для изменяющих запросов отклоняются. Внешние порты Qdrant и inference не публикуются.
- RAG передаёт фрагменты как данные в JSON, не выдаёт модели инструменты и сверяет цитаты на backend. Проверка идентификаторов не является семантической проверкой всех утверждений. Генерация через GigaChat API требует настроек сервера и явного подтверждения пользователя.
- Структурированные логи содержат идентификаторы, этапы, ошибки и время, без запросов, документов и токенов авторизации. История диалога хранится в SQLite намеренно и входит в backup.

Нативное использование LibreOffice требует внешней изоляции, указанной в [инструкции Windows](INSTALLATION_WINDOWS.md). При локальной работе без такой настройки DOCX использует текстовое представление.

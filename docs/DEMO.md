# Демонстрация

1. В «Документах» загрузите шесть файлов из `tests/fixtures`. Покажите форматы и ход индексации. При недоступной конвертации DOC покажите диагностическое сообщение в очереди.
2. В режиме «Только поиск» выполните запрос `TS-04`. Откройте TXT-фрагмент с номером строки и HTML-фрагмент с ID канала. Скачайте оригинал.
3. В локальном режиме задайте вопрос «Какая температурная уставка THERM-6 и какая мощность радиатора HX-9?». В корпусе ответы — 45,0 °C в Markdown и 28 Вт в PDF. Откройте обе ссылки.
4. При настроенном GigaChat API выберите его, подтвердите передачу фрагментов и повторите генерацию из сохранённого ответа. Сопоставьте формулировки и источники.
5. Откройте диагностику, затем продемонстрируйте переиндексацию и удаление одного файла.

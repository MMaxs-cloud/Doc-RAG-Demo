# Руководство пользователя

1. Откройте «Документы». Загрузите один или несколько файлов кнопкой или перетащите их в область загрузки.
2. Дождитесь статуса «Готов». При ошибке откройте сообщение задания. При неоднозначной кодировке выберите её в диалоге повторной обработки.
3. Откройте чат. Для точного термина или идентификатора выберите «Только поиск». Для ответа выберите «Ответ с источниками» и модель. Cloud checkbox подтверждает отправку вопроса, истории и найденных фрагментов в GigaChat API.
4. Нажмите на идентификатор источника. Карточка покажет координаты и цитату. «Открыть источник» откроет просмотр, «Скачать» сохранит оригинал.
5. Для повторного ответа выберите модель и «Повторить генерацию» в сохранённом диалоге. Поиск не запускается повторно, пока прежние источники доступны.
6. Для обновления результата обработки используйте переиндексацию. При удалении документ сразу скрывается из поиска. Файлы очищает worker.

В «Настройках» доступны параметры поиска и генерации, а в «Диагностике» состояния сервисов и последние ошибки.
